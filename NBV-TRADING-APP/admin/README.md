# Admin Suite

`AdminPanel.tsx` is the administrative control center for NBV Trading App.

### Modules:
1. **Financial Approval Queue**: One-click review, approval, or rejection of pending deposits and withdrawals with transaction ID verification.
2. **User Management**: View, search, update balances, toggle user roles, and audit referral trees.
3. **VIP Plans Manager**: Modify pricing, durations, and daily returns for investment tiers.
4. **Document Compliance**: Upload and update official SECP and FBR registration certificates.
5. **System Audit Logs**: Real-time record of all monetary movements and system events.
