# Application Components

- `DailyProfitCard.tsx`: Displays the live ticking 24h countdown clock (Hours, Minutes, Seconds) and handles one-click profit settlement synchronization.
- `InvestmentPlansComponent.tsx`: Interactive VIP plan selector with real-time profit calculators and EasyPaisa/JazzCash instructions.
- `WithdrawalComponent.tsx`: Bank/wallet details submission and instant withdrawal request workflow.
- `UserModulesModal.tsx`: Multi-tab modal for Referral Network, Deposit History, Withdrawal History, Profile Settings, and Live Support.
- `AdminReceiptGenerator.tsx`: Generates printable and shareable electronic payment vouchers.
- `NbvVisuals.tsx`: Official NBV green and gold circular crest badge.
- `PWAInstallButton.tsx`: Smart banner prompting Android users to install NBV Trading App directly to their home screen.
- `WelcomeScreen.tsx`: Brand intro splash screen showcasing the official NBV logo.
