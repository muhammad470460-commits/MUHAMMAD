# Configuration Files

- `package.json`: NPM package manifest, scripts, and production dependencies.
- `tsconfig.json`: TypeScript compiler options with strict type checking.
- `vite.config.ts`: Frontend bundler config with React plugin and dev proxy.
- `.env.example`: Template for environment variables.
- `manifest.json`: Web App Manifest defining the Android home screen app icon, theme color (`#062d1b`), name, and display mode (`standalone`).
- `sw.js`: Service worker caching static assets for offline capability and fast load times.
- `index.html`: Responsive HTML5 shell with viewport configuration, Google Fonts, and OpenGraph metadata.
